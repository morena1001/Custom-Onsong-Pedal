# Update, 1 / 4 / 26

I have decided to make a few changes that I will document here. 

### Modular pedal blocks
Firstly, the full pedal will be divided into blocks, where each block will have a pedal and correspond to a character ('a' - 'h'). The main block will also house the MCU and the battery. Each block will have at least one magentic, pogo pin based port that can easily connect to the other blocks. The main block and the last one, the one that corresponds to the letter 'h', will only have one port, signifying the start and end of the entire pedal system. The blocks will ideally have a small curve to them so that they don't stretch for too much and not fit underneath the piano. 

This past week I have been trying to create a consistent pogo pin connector setup, and have created many iterations. I am waiting to receive some new, stronger magnets to be able to handle the pressure and force created by the loaded springs on the pogo pins.

### Rechargeable battery
I have yet to start working on the rechargeable battery system for the main pedal block, but I don't think it should be too difficult. After doing some research. I think my easiest option would be to use an Ni-CD battery. The way to charge them safely is to simply use a resistor to limit the current. That option though might make it slow to charge. On the other hand, I could buy an li-ion battery and buy an actual module that will allow me to safely control the battery charge. 

I could also just use 4 AA or 3 AA batteries to power the whole thing, and honestly, I don't think that would be a bad idea. I could save money trying different solutions to create a rechargeable battery.
